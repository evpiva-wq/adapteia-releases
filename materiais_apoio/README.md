# Materiais de apoio

Esta pasta é lida diretamente pelo app "AdapteIAme" (tela "Materiais de
apoio" na Home) através da API pública do GitHub — qualquer arquivo colocado
aqui aparece automaticamente na lista dentro do app, pronto para o professor
ou responsável baixar.

Para publicar um novo material:

1. Adicione o arquivo (PDF, imagem, etc.) nesta pasta.
2. Faça commit e push para o branch `main`.
3. Pronto — o app já lista o arquivo na próxima vez que a tela for aberta
   (não precisa gerar uma nova versão do app nem publicar uma Release).

Este `README.md` é ignorado pela tela do app (não aparece na lista).
