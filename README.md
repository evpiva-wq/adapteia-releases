# AdapteIA

**Adaptar para incluir.**

O AdapteIA é uma ferramenta auxiliar da atenção humana: ajuda professores, famílias e profissionais de apoio a adaptar o conteúdo escolar para crianças com disgrafia, autismo, dislexia, TDAH e outras necessidades específicas. A tecnologia prepara o material; a decisão continua sendo de quem conhece a criança.

## Baixar (Android)

**[⬇ Baixar a versão mais recente (APK)](https://github.com/evpiva-wq/adapteia-releases/releases/latest/download/AdapteIA-latest.apk)**

Todas as versões: [Releases](https://github.com/evpiva-wq/adapteia-releases/releases).

### Como instalar
1. Baixe o arquivo no celular ou tablet Android.
2. Toque no arquivo. Se o Android pedir, permita instalar apps desta origem.
3. Abra o AdapteIA e siga as telas iniciais (Privacidade e Termos).

Depois de instalado, o próprio app avisa quando houver uma versão nova (Configurações › Verificar atualizações) e baixa a atualização — o Android sempre pede a sua confirmação para instalar.

## O que o app faz
- Adapta um material para a turma toda ou para um aluno específico, a partir da foto de uma página.
- Versão adaptada editável linha a linha, com PDF, mapa mental e conversa em áudio.
- Check-in diário de bem-estar (autorrelato), exercícios e atividades para casa.
- Adaptação de provas, revisão de provas respondidas e simulados de estudo.
- Perfis Profissional, Família e Criança, com PIN opcional.
- IA opcional, com chave própria; o nome do aluno nunca é enviado à IA. Sem IA, o app funciona por completo.

## Versão de testes
A versão atual é destinada a testes. Pode conter falhas: use apenas dados fictícios e não cadastre alunos reais sem o consentimento dos responsáveis. Para relatar problemas ou enviar sugestões, abra uma [issue](https://github.com/evpiva-wq/adapteia-releases/issues).

## Sobre este repositório
Este repositório contém **somente a distribuição** do aplicativo (APKs nas Releases) e a pasta `materiais_apoio/`, lida pelo app. O código-fonte não é publicado aqui.

O AdapteIA é uma ferramenta de apoio pedagógico e **não substitui** avaliação clínica, diagnóstico ou acompanhamento especializado.
